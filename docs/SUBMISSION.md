# 提交指引

## 如何提交

1. Fork 本仓库到你的 GitHub 账号。
2. 在仓库内完成实现。
3. 将代码、文档和测试一起提交。
4. 向本仓库发起 Pull Request。
5. 在 Pull Request 描述中注明：
   - 完成的功能范围
   - 未完成的部分
   - 启动与测试方式
   - 演示视频或可运行的演示脚本

## 交付物清单

- [ ] 源代码可在本地运行
- [ ] 启动说明写入 `README.md`
- [ ] 完成 `DESIGN.md`
- [ ] 完成 `AI_USAGE.md`
- [ ] 至少包含核心接口的自动化测试
- [ ] 提供演示视频或演示脚本

## 演示要求

面试前请准备一份约 5 分钟的演示，包含：

1. 启动服务
2. 创建一个成功任务
3. 创建一个失败任务
4. 取消一个运行中的任务
5. 查看日志和产物
6. 说明你如何验证 AI 使用过的代码
