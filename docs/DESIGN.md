# 设计方案模板

请在完成题目后填写本文件，说明你的设计过程和关键决策。

## 需求理解

请用一两段话说明你如何理解题目，以及你界定的主要功能边界。

## 总体架构

- 服务由哪些模块组成
- 各模块的职责
- 请求处理流程

## 接口设计

列出主要接口、请求字段和响应结构。

## 任务状态管理

说明状态如何流转，以及如何处理：

- 超时
- 取消
- 失败
- 服务重启

## 安全与可靠性

说明你如何做到：

- 只执行预定义命令
- 控制日志大小
- 清理临时文件和子进程
- 控制并发资源

## 测试方案

- 测试覆盖了哪些路径
- 如何运行测试
- 还有哪些测试没有覆盖

## 已知限制与改进方向

诚实列出当前实现的主要限制，以及你计划如何完善。

## 如果再给一天，你会优先做什么？

请说明优先级和理由。
